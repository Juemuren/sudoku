# 规划

## WebUI

目标：实现浏览器界面，包含终端界面的所有功能。

- 使用 React + Vite 构建界面。
- 复用 `domain/` 和 `app/`。
- 在浏览器侧实现 `SaveStore`，设计存档导入、导出与覆盖确认。

## Human Solver

目标：根据当前棋盘给出一步可解释的推理。

- 在 `domain/` 中定义求解步骤：目标格、数字、技巧及理由。
- 基于 `rules.ts` 的候选数，先实现唯一候选数和唯一位置两种基础技巧。
- 每次只返回一个步骤；找不到步骤时返回无结果，不使用回溯猜测。
- 为每种技巧添加能验证步骤正确性和说明内容的题例，再接入游戏提示功能。
